# ContentForge-AI v0.4 Vision: Premium AI Creative Production Engine

## Mission

Transform ContentForge-AI from a functional video automation pipeline into a
**premium AI creative production engine** whose output is indistinguishable from
a video edited by a skilled short-form content editor.

## Primary Input → Output

```
Website URL + Raw desktop screen recording
        ↓
AI Creative Production Engine
        ↓
Professionally edited vertical Reel
+ Grounded AI narration
+ Word-synchronized captions
+ Intelligent framing
+ Cinematic/premium motion
+ Licensed background music
+ Tasteful sound effects
+ Dynamic visual emphasis
+ Strong hook + CTA
+ Premium cover
+ Caption + hashtags + metadata
+ Quality report (technical + creative)
```

## Quality Principles

### Optimize For

| Priority | Target |
|---|---|
| 1 | Viewer retention |
| 2 | Clarity and information density |
| 3 | Visual quality and professional composition |
| 4 | Natural narration |
| 5 | Mobile readability |
| 6 | Brand consistency |
| 7 | Factual grounding (never fabricate) |
| 8 | Maintainability |

### Non-Negotiable: "Good Video" ≠ "Valid Video"

FFmpeg succeeding is **not** a quality signal. Every job must pass:

- **Technical quality**: valid MP4, correct codec/dimensions/FPS, valid audio,
  no corruption, correct duration, captions render, cover exists
- **Creative quality**: strong opening, useful framing, good pacing, readable
  captions, natural narration, music fits mood, useful zooms, strong CTA,
  attractive cover

## New Architecture: Gemini-Powered Intelligence

v0.4 introduces **Gemini** as the AI backbone:

- **Gemini 2.5 Flash** for text tasks (scripting, hook generation, creative planning)
- **Gemini Vision** for frame-level understanding of screen recordings
- **Gemini TTS** (future) for narration when available
- Full **offline fallback** preserved — the pipeline never breaks without AI

## Design Constraints

- **8 GB RAM laptop** — adaptive sampling, streaming, no huge models
- **CPU-only** — no GPU dependency
- **Offline-first** — core pipeline works without internet
- **Fedora Linux** — primary target platform

## Success Criteria

The project is complete when `studentofferco.com.mp4` produces a Reel that:

1. Immediately hooks the viewer (first 3 seconds)
2. Understands the demonstrated website from visual evidence
3. Explains what is happening with grounded narration
4. Shows the important UI without destructive cropping
5. Uses smooth camera movement and intelligent zooms
6. Has natural AI narration synchronized to visuals
7. Has premium word-highlighted captions
8. Uses licensed background music
9. Has professional pacing and visual hierarchy
10. Contains a strong CTA
11. Has an attractive branded cover
12. Passes both technical and creative QA
